# kakjoeprojects_sosmed

Social media for Jordan's products.

| Folder | What's in it |
|---|---|
| `<product>/product_knowledge/` | What the product is, its voice, brand and images. Read before writing any post. |
| `<product>/instagram/<date-slug>/` | One Instagram post: images, `caption.md`, `post.json`. |
| [`tools/instagram/`](tools/instagram/README.md) | Script that checks a post folder and schedules it on Instagram through Postiz. |

Products: [Ngatur Duit](ngaturduit.my.id/product_knowledge/README.md),
[cariinkerja.id](cariinkerja.id/product_knowledge/README.md),
